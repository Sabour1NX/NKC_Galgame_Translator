Set up your first game

  1. Choose your interface language and accept the user terms. You can change the language and theme later in Settings.
  2. In Settings, open API connections. Choose a slot and provider, then enter the endpoint, model ID and API key. The endpoint must support OpenAI-compatible Chat Completions. For Ollama or another local server, start the server first. Use the model ID installed on that server.
  3. Open Game translation and select the game’s own window. Choose the source and translation languages. Select a game profile to resume its terminology and context.
  4. Choose Entire game window, or use Select areas to mark one or more dialogue boxes. Start translation and switch back to the game. To remove the overlay, choose Stop and show original.

Profiles, terms and pasted text

Use a separate profile for each game. Notes can record how characters address each other or how to translate a place name. Reopening a saved profile restores its context.

Use Glossary to suggest a preferred translation. Game-specific terms take precedence over shared terms. Completed translations appear in the profile history.

To translate a passage from the clipboard, open Translate text manually and paste the passage. It uses the game profile and language pair selected on the main tab.

Recognition and display

Use Lightweight mode to translate text near the pointer. In full-window mode, pointing at a missed line gives that area priority while recognition continues elsewhere.

CUDA OCR requires the optional CUDA add-on, a supported NVIDIA GPU and a compatible driver. The default inference memory budget is 1,024 MiB. Move the quality slider toward accuracy to favor detail. Loading the model can take a few seconds.

Image recognition via the LLM backend sends selected game regions to the configured provider when set to Force. Choose Off to recognize text locally. Online text translation still sends recognized text to the backend.

Choose a font that supports the translation language, or enable automatic style matching. Set a minimum and maximum size to fit long lines. Settings also lets you include translated text in screenshots.

Keyboard shortcuts and exports

The default global shortcuts are Ctrl+Alt+T to start or stop, Ctrl+Alt+R to translate the current screen again and Ctrl+Alt+L to toggle Lightweight mode. You can change the bindings in Settings.

Enable the optional localization toolkit to save page screenshots and source–translation pairs. Select TXT, JSON or CSV, an export folder and a delay. The default delay is 15 seconds so a later, more complete reading can replace an early result before export.

If a translation does not appear

First check the selected window and return focus to the game. For a small or ornate font, select the dialogue area or adjust OCR quality. The footer shows the active translation model.

HTTP 401 usually means the key was rejected. For HTTP 404, check the endpoint and model ID. For HTTP 429, wait before retrying or lower concurrency. LLM_CONNECTION and LLM_TIMEOUT indicate a connection failure or timeout. For a local backend, check that its server is running.

In Settings, each theme has its own graph style and line colors. The two lines track utilization and memory. When GPU OCR is active they show GPU utilization and VRAM.
