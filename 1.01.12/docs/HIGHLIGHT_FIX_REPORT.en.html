04 / A HARNESS FOR TRANSLATION
The model understands. The Harness coordinates.
NKC_Galgame_Translator is a Harness connecting the game, recognition and translation models. Context and display have separate responsibilities; search notes, reasoning and citations do not enter the in-place translation.


CONTEXT / CONTEXT LAYER
Source text, game identity and compressed history
↓
ContextAgent · bounded background-understanding subtask
↓
DeepSeek web search · optional server-side tool
↓
Bounded summary, sources and actual execution status
DISPLAY / DISPLAY LAYER
Whole-frame recognition → source-pixel anchors
↓
Separate translation request → translation-only stream
↓
Object revision and cancellation checks → peer font size
↓
C++ / GDI · in-place layout and buffered submission
Bounded context references inform the translation prompt. Web pages, screenshots and history remain untrusted data. Models receive no arbitrary filesystem, shell or client-side URL-fetch tools.


Budgets and boundaries stay in the program.
Context and translation share concurrency, request budgets and token accounting, with cancellation and timeout limits. Web search is optional. Unsupported models, budget or network failures expose the actual fallback state; an unused search is never reported as completed. Context can be cached instead of searched again for each frame.
Quality first, with the cost of extra requests.
Visual review and background search can aid understanding, but add requests, cost and waiting. The three paired timing runs above disable web context; they do not represent latency with every assistance feature enabled. Public defaults leave web context off; users can choose it in settings.

Traceable data, explicit scope.

Recognition evaluation
Source-image SHA256 values match; manual zones and reference text are retained. Character accuracy = 100 × (1 − edit distance / reference characters), with NFKC, whitespace removal, curly-quote normalization, case retained and (y,x) ordering. Cargo labels and price columns affect this zoned metric. The striped HELP item and status date are excluded from the three-frame annotations.
Character accuracy is not localization IoU, semantic translation correctness or a general-game success rate. The NEEDY sample is reported separately and does not substitute for a broad quality evaluation.
