二色蝶·游戏实时翻译

顶部入口改为「Galgame 翻译」。快捷键启动时显示独立提示。设置可选二色蝶、霓虹波、modern_windows 和随心配，随心配接受 #RRGGBB。霓虹波使用个人主页的紫、粉、薄荷青配色与矢量山景，主窗口退到后台后暂停动画。

汉化组工具（Beta）默认关闭，协议确认后首次询问，也可在设置中启用。默认保存到软件根目录。单页翻译完成后截取游戏窗口，并在默认 15 秒的遴选期后写入完成度和 OCR 证据更好的译文。等待可设 1–120 秒。按档案名称和日期建文件，同日开始新的翻译会话时追加序号。支持 TXT、JSON 和 CSV，TXT 保留时间戳、原文、空行与译文。截图以同名前缀保存为 PNG。JSON 与 CSV 含对应截图文件名。是否在截图中显示译文取决于截图设置。

Aoichan 的双箭头保留在游戏画面。识别副本先排除箭头，再生成文字框，译文覆盖在原文字形边缘收口。自动存档说明的绿色字幕按实际字色重建背景，同一物理行只采用一条识别结果。

Aoichan「要跳过开场吗？」的完整 OCR 读法合并为同一个文字对象。闪烁提示或短暂的识别框变化出现时，已显示的译文保留字号、字距和基线。游戏窗口大小真实变化时重新排版。

Aoichan 中的人名「葵」按已确认的原文校正。对白末尾的闪烁双箭头从文字定位和覆盖范围中排除。合租广告和随后的旁白独立跟踪，合租房、押金和礼金等措辞按对应原文显示。

设置中的「画面变化敏感度」范围为 0–100，默认 70。数值越高，越容易识别切场和局部原文变化。确认原文已变时立即清除对应译文，即使新译文仍在生成。画面稳定时，旧译文暂留默认 250 毫秒，可设为 0–10000 毫秒，设为 0 关闭。已确认滚动时，短暂丢失的译文沿原方向最多暂留 80 毫秒。游戏进程退出时自动停止翻译。

API 配置

默认接口采用 OpenAI 兼容的 Chat Completions 格式。三个槽位都可选择 DeepSeek（推荐）、ChatGPT、其他（自定义）、Ollama 或本地。DeepSeek 默认地址为 https://api.deepseek.com，推荐模型为 deepseek-flash。Ollama 预填 http://127.0.0.1:11434/v1；本地预填 http://127.0.0.1:1234/v1，地址和端口可改。先启动本机服务，再填写其中已加载的模型名。服务无需认证时，密钥留空即可翻译。图片识别需要支持图片输入的模型。

0.01.27 整组拟合与短续行

同一段正文以源行墨迹高度的中位数作稳定参考。至少三行且有至少两条宽正文、宽正文占多数时，极短续行或明显低墨迹行不单独把整组压成极小字号。单个 Region 内，短续行溢出可尝试把完整字簇分配到紧邻前行已测得的空余宽度，最多检查 64 个候选且续行至少保留一簇；行框不扩大。不能容纳的弱证据行保留原文字像素。跨 Region 不挪动文字；普通、中宽长译文仍约束共同字号。

流式阶段显示当前参考字号能容纳的前缀，完整译文仍累计保存；完成后再执行整组拟合和满宽字距。标题、列、源字号/风格、固定字号与显式字号上限边界保留。少数弱框可能仍显示原文，流式尾部可能等到 final 后出现。这是显示修复，不代表 OCR 或语义翻译准确率提高。

不新增用户配置，不改变 ABI 2 或原有导出签名；原生诊断新增 font_intrinsic_px 与 lines[].drawable。fits=true 表示可靠约束行已拟合，弱异常行仍可能 drawable=false，逐行可见性应检查该字段。本版 C++ 核心需要重新编译与验收，旧版 native audit 不构成本版二进制证据。

0.01.27 CUDA 识别与实际回退

首次语言设置和常规设置共用 CUDA 控件。cuda_enabled 默认开启；只在 OCR 自动模式且源语言为英语、日语或中文时尝试 CUDA。手动 Windows / Pixel 模式明确走 CPU；自动模式检测到经典英语像素画面且便携识别可用时优先 CPU Pixel 路径（pixel_priority）；其他语言继续使用已有本地识别。组件缺失、无兼容 GPU、模型校验或推理失败时回退 Windows / Tesseract，并显示实际状态，不能把“文件已安装”当作“CUDA 已运行”。失败后的当前 OCR 实例不反复重试 GPU，修改设置后停止并重新开始。

设置 默认 范围与作用
cuda_enabled true 开关；不自动下载或安装组件
cuda_quality 75 0–100，高性能到高精度；线性调节检测长边，按 32 像素量化
cuda_memory_mb 1024 256–16384 MiB；推理内存 arena 预算，不会强行占满 1 GiB，运行库和驱动另有开销

检测长边约为 768 + 11.52 × cuda_quality 后按 32 像素量化；75 对应 1632 像素。仅缩小超出上限的图像，小图在不同档位可能等效；数值不是准确率百分比，也不保证单调提速或提高精度。CUDA 模型为 PP-OCRv6-small，GPU/依赖验证结果以本版报告为准，不提前声称所有 NVIDIA 显卡可用。

启用可选云端 AI 图像精读时，CUDA 已输出的行仅在置信度不低于 95 且没有拒绝标记时直接送译，其余仍走核验路径。95 是模型分数门槛，不是 95% 实测准确率承诺。CUDA 本地 OCR 不上传图片；云端精读仍遵循独立开关和图片发送规则。

游戏翻译 Harness：理解与显示分层

二色蝶把模型放在有边界的游戏翻译流程中：程序管理原文与坐标、语境参考、请求额度、对象修订和原位显示，模型负责理解与译文。质量优先意味着先验证文本完整性和定位，再考虑缓存与调度；增加识别步骤或联网参考可能增加等待时间。

程序先读取完整文字区域，再整理有用的背景参考、请求当前译文，最后按原行位置显示。这些步骤各自独立：联网资料用于帮助理解，游戏中只显示本段译文。

在“设置 → 上下文层与显示层”可开启联网理解游戏背景；公开默认关闭，保存后重新开始翻译。仅官方 DeepSeek deepseek-flash 的已支持服务端搜索接口使用此扩展，其他兼容服务仍可普通翻译。模型决定是否搜索，界面区分实际取得来源与未搜索；启用开关不代表每次都进行了搜索。背景参考缓存不替代后续译文请求。联网理解接口与费用边界。

同一连续正文组保持统一字号。短译文完成后仍可增大字距填满原行；长行在自动范围内要求缩字时，同组一起缩小，不能只放大其中一行。标题、不同源字号、不同列和字体风格保持独立；达字号下限仍放不下时保留原文。坐标来自本地 OCR，字号一致不代表错误的 OCR 框已经被修正。

当前实际游戏测试改用 NEEDY GIRL OVERDOSE，关注日文小字、多色面板和段内字号；既有 Space Rogue 固定截图保留为回归材料。测试范围、计时和剩余限制以本版测试与性能报告为准，不把一张图的结果推广为全游戏结论。

多区域与自动字体

在屏幕翻译页选择游戏窗口，点击“框选区域”。连续拖动添加 1–8 个不重叠矩形；按 Enter 确认，按退格或右键撤销最后一个，Esc 取消并保留原选择。每框至少 20 × 20 像素；合并外接矩形每轴不超过 4096 像素。请把一整段文字留在同一框内，并留少量边距。区域随游戏客户区移动，缩放后裁到客户区；更换游戏窗口后恢复整个客户区。选区仅在本次界面会话保留。

多个选区使用同一帧捕获，框外间隙先遮成黑色再进入 OCR 或可选 AI 图像精读；语句团和对象关联不跨选区。框选不同区域不会分别启动多个 OCR 进程，也不改变翻译并发上限。全屏游戏建议切换窗口模式。

打开“设置 → 译文外观 → 按原文自动选择相似风格字体（支持目标语言）”，保存后重新开始翻译。程序根据原文字形近似选择像素、衬线、无衬线或等宽风格，并逐框检查字体是否支持目标语言与当前译文字形。无需下载字体。默认关闭，关闭时仍使用手动字体。自动字号及上下限独立设置，过长译文继续在允许范围内缩小。

字体匹配不等于还原游戏字体；装饰字、复杂背景、短词和误识别可能影响风格判断。字形不全时改用已安装且覆盖译文的后备字体；没有合适字体时保留原文。当前自动覆盖检查保守支持 BMP 字符；含补充平面字符或 emoji 的该框保留原文，可切回手动字体使用 Windows 字体回退。

API、记录与许可

需要用户自行提供兼容 OpenAI 接口的 HTTPS API、模型与可用密钥；服务费用由对应服务商计收。三个 API 槽位独立保存，密钥加密绑定当前 Windows 用户。公开试用版不含私人密钥，也没有额外设置试用倒计时。
