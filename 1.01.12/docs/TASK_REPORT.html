0.01.30 任务报告

焦点不打断翻译

短按钮文本确认后，采集画面的按钮内侧像素相同时继续使用原识别结果和已有译文。移动焦点产生的描边不会让 OK 重新进入翻译队列。

按源字形高度排版

按钮译文只使用经检查的留白，并按原中心绘制。短标签等完整译文后一次显示。字号仍受设置与实际空间约束。

安装和迁移

发行程序面向 Windows x64。配置、加密密钥与档案由本机迁移。公开包用于分发。

验证覆盖

  • 焦点描边和 OCR 误读的回归测试确保保留已有译文，并验证真实字形变化仍更新。
  • Windows 原生绘制回归检查字号、居中以及边界。
  • 历史游戏原始截图的 CUDA 实测确认 OK 和 Cancel 都可使用经确认的留白。游戏内连续交互的表现仍需实机观察。
  • 中文、英文、日文五个主页面及配置对话框使用隔离配置截图。结果随交付包提供。
