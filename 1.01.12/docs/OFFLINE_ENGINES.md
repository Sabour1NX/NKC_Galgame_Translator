# 本地翻译路线变更 · 0.01.27

0.01.27 加入可选 CUDA OCR、后台联网语境与整组字号修复。本版新增同图 OCR 评审，对照 0.01.15，分别报告冷启动、背景变化热路径、复访缓存和逐字精度；真实 API 链路另列。历史证据保留原版本标签，当前方法与范围见性能报告及 TEST_REPORT.json。

适用版本：0.01.27 · 文档复核：2026-11-18。历史记录保留原版号。


0.01.20 移除本地专家系统，改为纯 AI 生成译文。不接入新的离线神经翻译库，也不在无 API 时自动调用旧词典替换。

原有词典/整句数据保留，供浏览、迁移和有界 AI 参考；本地 OCR、几何分析与档案压缩仍可运行。没有 API 时不能生成新译文。早期 Argos/CTranslate2 等调研属于历史候选，不能据此声称本版集成或支持这些运行时；依赖清单以本版锁文件及 [DEPENDENCIES.md](DEPENDENCIES.md) 为准。
