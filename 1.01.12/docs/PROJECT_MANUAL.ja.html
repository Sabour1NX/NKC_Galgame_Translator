NKC_Galgame_Translator · 1.01.12 · 操作ガイド

ゲーム画面の文字を翻訳する

セリフや選択肢が元の位置に訳文で表示されます。クリックやキー操作はそのままゲームに届きます。

どのテーマでも初期設定は折れ線です。「設定」のテーマ欄で「山並み (beta)」を選んで保存すると、CPU または GPU の使用率に山並みが付きます。RAM と VRAM の使用量は常に折れ線で表示されます。

初めて使うとき · ゲームごとのメモと用語集 · 文字の読み取りと表示 · Shortcut と対訳の書き出し · 訳文が表示されないとき

初めて使うとき

  1. 表示言語を選び、利用規約を確認して同意します。表示言語とテーマは後から「設定」で変更できます。
  2. 「設定」の「API 接続設定」を開きます。接続先を保存する Slot を選び、サービス、URL、Model ID、API Key を設定してください。OpenAI 互換の Chat Completions API に対応しています。Ollama などをローカルで使う場合は、先に Server を起動し、そこに導入した Model の ID を指定します。
  3. 「ゲーム翻訳」でゲーム本体の Window を選び、原文と訳文の言語を指定します。前回の続きなら、同じゲームの Profile を選びます。
  4. 「ゲーム画面全体」を選ぶか、「範囲を指定」でセリフ欄などを囲みます。複数の範囲も指定できます。翻訳を開始してゲームに戻ってください。「停止して原文に戻す」を押すと訳文の表示が消えます。

ゲームごとのメモと用語集

Profile には訳文と会話の流れが保存されます。「翻訳用メモ」に登場人物の呼び方や地名の訳し方を記録しておくと、次に同じ Profile を開いたときも参照できます。

「用語集」では原文と優先する訳語を登録できます。ゲーム固有の用語は共通の用語より優先されます。過去に翻訳した文は Profile の履歴で確認してください。

コピーした文章を訳すには「テキスト翻訳」に貼り付けます。「ゲーム翻訳」で選んだ言語と Profile が適用されます。

文字の読み取りと表示

「軽量モード」を選ぶと、ポインターの周辺だけを翻訳します。画面全体を翻訳しているときも、読み飛ばされた文字にポインターを近づけると、その付近を優先して読み取ります。

CUDA OCR を使用するには、対応する NVIDIA GPU、ドライバー、追加の CUDA パッケージが必要です。推論用 VRAM の既定値は 1,024 MiB です。細かい文字を読み取りたい場合はスライダーを高精度側に動かしてください。初回の Model 読み込みには数秒かかることがあります。

「LLM による画像認識」を「強制」にすると、選択したゲーム画面の画像を接続先に送ります。「オフ」では文字の読み取りをこの PC で行います。オンライン翻訳では、読み取った文章が翻訳サービスに送られます。

訳文の言語に対応した Font を選ぶか、原文に近い書体を自動で選ぶ設定を有効にします。長い訳文が収まるよう、文字サイズの上限と下限を指定できます。Screenshot に訳文を含めるかどうかも設定できます。

Shortcut と対訳の書き出し

初期設定では Ctrl+Alt+T で翻訳を開始・停止し、Ctrl+Alt+R で今の画面を再翻訳します。Ctrl+Alt+L は軽量モードの切り替えです。キーの組み合わせは「設定」で変更できます。

翻訳チーム用ツールを有効にすると、ページごとの画像と対訳を保存できます。保存先と形式（TXT、JSON、CSV）を選んでください。待ち時間の既定値は 15 秒です。その間に読み取り結果が改善されれば、より完全な対訳を採用できます。

訳文が表示されないとき

ゲーム本体の Window が選ばれているか確認し、ゲームを手前に表示してください。小さな文字や装飾文字は、セリフ欄だけを囲むか、認識精度を調整してみてください。使用中の翻訳 Model は画面下部に表示されます。

HTTP 401 が出たら API Key、HTTP 404 なら URL と Model ID を確認します。HTTP 429 はしばらく待つか同時 Request 数を減らして再試行してください。LLM_CONNECTION は接続失敗、LLM_TIMEOUT は応答待ちの Timeout です。ローカルで使う場合は Server の起動状態も確認してください。

リソース Chart の形式と 2 本の線の色は、テーマごとに設定できます。GPU で文字認識を行っている間は、GPU 使用率と VRAM 使用量が表示されます。
