NKC_Galgame_Translator · 二色蝶

首次接受使用协议后选择界面主题。通过安装包安装时，所选安装语言也将用于首次启动，安装完成后打开对应的 产品介绍。

在「游戏实时翻译」中选择要翻译的游戏窗口。快捷键启动时显示独立提示。设置可选二色蝶、霓虹波、modern_windows 和随心配，随心配接受 #RRGGBB。霓虹波使用个人主页的紫、粉、薄荷青配色与矢量山景，主窗口退到后台后暂停动画。

汉化组工具（Beta）默认关闭，协议确认后首次询问，也可在设置中启用。默认保存到软件根目录。单页翻译完成后截取游戏窗口，并在默认 15 秒的遴选期后写入完成度和 OCR 证据更好的译文。等待可设 1–120 秒。按档案名称和日期建文件，同日开始新的翻译会话时追加序号。支持 TXT、JSON 和 CSV，TXT 保留时间戳、原文、空行与译文。截图以同名前缀保存为 PNG。JSON 与 CSV 含对应截图文件名。是否在截图中显示译文取决于截图设置。

Aoichan 的双箭头保留在游戏画面。识别副本先排除箭头，再生成文字框，译文覆盖在原文字形边缘收口。自动存档说明的绿色字幕按实际字色重建背景，同一物理行只采用一条识别结果。

Aoichan「要跳过开场吗？」的完整 OCR 读法合并为同一个文字对象。闪烁提示或短暂的识别框变化出现时，已显示的译文保留字号、字距和基线。游戏窗口大小真实变化时重新排版。

Aoichan 中的人名「葵」按已确认的原文校正。对白末尾的闪烁双箭头从文字定位和覆盖范围中排除。合租广告和随后的旁白独立跟踪，合租房、押金和礼金等措辞按对应原文显示。

设置中的「画面变化敏感度」范围为 0–100，默认 70。数值越高，越容易识别切场和局部原文变化。确认原文已变时立即清除对应译文，即使新译文仍在生成。画面稳定时，旧译文暂留默认 250 毫秒，可设为 0–10000 毫秒，设为 0 关闭。已确认滚动时，短暂丢失的译文沿原方向最多暂留 80 毫秒。游戏进程退出时自动停止翻译。

各主题默认使用普通折线。在「设置 → 界面主题」选择「矢量山峰 (beta)」并保存，即可给 CPU 或 GPU 利用率折线添加山脊。内存和显存用量始终以普通折线显示。

API 配置

默认接口采用 OpenAI 兼容的 Chat Completions 格式。三个槽位都可选择 DeepSeek（推荐）、ChatGPT、其他（自定义）、Ollama 或本地。DeepSeek 默认地址为 https://api.deepseek.com，推荐模型为 deepseek-flash。Ollama 预填 http://127.0.0.1:11434/v1；本地预填 http://127.0.0.1:1234/v1，地址和端口可改。先启动本机服务，再填写其中已加载的模型名。服务无需认证时，密钥留空即可翻译。图片识别需要支持图片输入的模型。

在 Windows x64 上读取游戏窗口文字，将译文放回原位置。点击、方向键和确认键仍由游戏处理。

开始使用

  1. 首次启动确认软件语言，阅读并同意使用协议。软件语言初始跟随 Windows，可在设置里切换中文、English 或日本語。
  2. 到「设置 → API 配置」选择一个槽位，填写 OpenAI 兼容 API 地址、模型及密钥。三个槽位分开保存，密钥由当前 Windows 账户加密。
  3. 返回「屏幕翻译」，选择游戏实际窗口与语言方向。可选游戏档案，用来恢复语境与语言设置。
  4. 选择「整个游戏窗口」或框选一个或多个文字区域，再点击「开始翻译」。切回游戏窗口查看原位译文。「停止 / 还原」撤下覆盖层。

五个页面

屏幕翻译

选择游戏、语言、档案和识别区域。档案管理可以继续已有档案、保存备注或删除不再需要的档案。

翻译词典

可为当前游戏与语言对添加或导入首选译法，也可使用跨游戏通用词典。匹配术语作为 AI 参考，游戏条目优先。

自动保存的完整译文在「译文与语境档案」，手动术语表为空时也可能有历史记录。

文本翻译

粘贴原文，复核单句结果和词典参考范围。

使用协议

查阅免责声明与 MIT。接受状态随本机配置保存。

设置

配置 API、OCR、字体、截图是否包含译文、语言标注、快捷键及翻译并发和本次请求上限。

字体、OCR 与刷新

LLM后端识别图片 在设置中选择强制或关。强制模式按设置的间隔发送变化的游戏选区，失败时继续显示本地结果。

  • 自动字号跟随源文字，可设置最小值和最大值，也可以固定字体及字号。译文过长时由自动字号在指定范围内缩小。短按钮如 OK 和 Cancel 在经截图确认的内侧留白范围内居中，保留焦点框。
  • 游戏中的按钮焦点移动属于正常操作。按钮内部字形和留白像素相同时，已有译文继续使用。滚动或真实字形变化会重新核对位置。
  • 默认 Ctrl + Alt + R 重新识别并翻译当前画面，可在设置中修改或关闭。
  • 在首次设置或「设置」启用 CUDA OCR。默认显存预算 1024 MiB，可调。精度与性能滑条为 0–100。需要兼容的 NVIDIA 驱动与独立 CUDA 扩展。像素字体场景仍可能优先使用 CPU。
  • 窗口选错时，请点「刷新窗口」并选实际游戏进程。首次加载 CUDA 模型可能需要数秒。OCR 可用时仍需已配置的翻译 API 才能产生新译文。

工程结构与工作流

游戏窗口截图→整帧 OCR→ROI / 字形核对→文本跟踪→译文与语境处理→原位绘制
目录或模块职责与接口
nkc_galgame_translator/ocr.pyPython 调用 Windows OCR、便携 Tesseract 或 CUDA。识别结果带文本和矩形，跟踪前转换为屏幕坐标。
nkc_galgame_translator/pipeline.py采集线程、跟踪与翻译池。输出带稳定对象 ID 和修订号的更新，过期修订不会覆盖新对象。
nkc_galgame_translator/translation.py经 OpenAI 兼容 POST /chat/completions 流式请求；以游戏和语言对为边界保存术语与历史。
native/C++17 提供窗口采集和 GDI 原位绘制。gl_overlay_labels 使用与区域数相同的标记数组，居中布局需要一个有效原文行。既有 ABI 2 保留。
tools/辅助 OCR 进程、离线跑分、截图与 Windows x64 构建工具。依赖锁文件随源码分发。
config/ 与 data/本机配置与 SQLite 记录。分享时使用公开包；私有开发版包含本机凭据与档案。
