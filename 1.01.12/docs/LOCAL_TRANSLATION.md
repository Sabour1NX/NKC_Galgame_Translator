# 参数与压缩语境档案 · 0.01.27

## 0.01.27 CUDA 识别与实际回退

首次语言设置和常规设置共用 CUDA 控件。`cuda_enabled` 默认开启；只在 OCR **自动模式**且源语言为英语、日语或中文时尝试 CUDA。手动 Windows / Pixel 模式明确走 CPU；自动模式检测到经典英语像素画面且便携识别可用时优先 CPU Pixel 路径（`pixel_priority`）；其他语言继续使用已有本地识别。组件缺失、无兼容 GPU、模型校验或推理失败时回退 Windows / Tesseract，并显示实际状态，不能把“文件已安装”当作“CUDA 已运行”。失败后的当前 OCR 实例不反复重试 GPU，修改设置后停止并重新开始。

| 设置 | 默认 | 范围与作用 |
|---|---|---|
| `cuda_enabled` | `true` | 开关；不自动下载或安装组件 |
| `cuda_quality` | `75` | 0–100，高性能到高精度；线性调节检测长边，按 32 像素量化 |
| `cuda_memory_mb` | `1024` | 256–16384 MiB；推理内存 arena 预算，不会强行占满 1 GiB，运行库和驱动另有开销 |

检测长边约为 `768 + 11.52 × cuda_quality` 后按 32 像素量化；75 对应 1632 像素。仅缩小超出上限的图像，小图在不同档位可能等效；数值不是准确率百分比，也不保证单调提速或提高精度。CUDA 模型为 PP-OCRv6-small，GPU/依赖验证结果以本版报告为准，不提前声称所有 NVIDIA 显卡可用。

启用可选云端 AI 图像精读时，CUDA 已输出的行仅在置信度不低于 95 且没有拒绝标记时直接送译，其余仍走核验路径。**95 是模型分数门槛，不是 95% 实测准确率承诺**。CUDA 本地 OCR 不上传图片；云端精读仍遵循独立开关和图片发送规则。

0.01.27 加入可选 CUDA OCR、后台联网语境与整组字号修复。本版新增同图 OCR 评审，对照 0.01.15，分别报告冷启动、背景变化热路径、复访缓存和逐字精度；真实 API 链路另列。历史证据保留原版本标签，当前方法与范围见性能报告及 TEST_REPORT.json。

## 0.01.27 上下文边界

可选上下文层只声明 DeepSeek 服务端联网搜索工具，之后的纯译文请求不声明工具。两层共用额度、并发与 Token 统计。游戏文字、历史、网页与摘要都是不可信参考，客户端不自动访问返回 URL、不执行函数或命令，也不让模型改变本地原文坐标。精确请求、元数据、超时与缓存契约见 [CONTEXT_AGENT.md](CONTEXT_AGENT.md)。

## 数值设置

| 配置键 | 用途 | 范围 | 默认 |
|---|---|---|---|
| `context_max_chars` | AI 历史语境字符预算 | 512–16000 | 6000 |
| `context_history_records` | AI 历史语境记录上限 | 1–64 | 24 |
| `ocr_refine_workers` | OCR 区域细化线程 | 1–8 | 4 |
| `vision_interval_ms` | AI 图像精读最短间隔（毫秒） | 1000–60000 | 3000 |
| `translation_workers` | 翻译并发上限 | 1–16 | 8 |
| `tracking_workers` | 文字匹配工作线程 | 1–4 | 2 |
| `max_tracked_objects` | 同时追踪文字框 | 1–32 | 32 |
| `capture_interval_ms` | 截图间隔（毫秒） | 50–2000 | 50 |
| `settle_ms` | 文字稳定等待（毫秒） | 0–3000 | 80 |
| `track_missing_frames` | 漏识别保留帧数 | 0–30 | 10 |
| `ocr_min_confidence` | 便携 OCR 最低置信度 | 0–100 | 55 |
| `max_requests` | 本次运行 API 请求额度 | 0–10000 | 80 |
| `request_timeout` | API 超时（秒） | 1–120 | 30 |
| `max_retries` | 失败重试次数 | 0–2 | 1 |
| `max_output_tokens` | 翻译最大输出 Token | 32–4096 | 512 |
| `max_input_chars` | 单次最大输入字符 | 64–16000 | 4000 |

整数拒绝 bool/浮点/NaN/无穷值，控件字符串只接受最多6位十进制整数。布尔值必须是真正 bool。`max_concurrency` 与 `translation_workers` 同步。`overlay_font_family` 为1–31个UTF-16单元且无控制字符；`app_language` 为 zh-CN/en/ja，`ocr_mode` 为 auto/native/pixel。

## 存储与语境

`ContextArchive` 每条 JSON 事件最多1MiB，以 zlib level 6 无损压缩。数据库表 `ai_context_events(id,scope_key,created_at,payload,raw_bytes)` 按范围和递增ID索引。读取坏压缩记录时跳过，不改写原记录；解压输出上限1MiB，拒绝尾部多余数据。历史条数默认24，查询最多64；完整存储不因提示预算而截断。

发送模型的是包含 `kind`, `user_context`, `terms`, `recent_translations` 的 JSON 摘录，总序列化字符数不超过 `context_max_chars`。匹配术语最多32条，每字段最多256字符；近期原/译文字段最多512字符，语境摘录最多200字符。只有本次参考被缩减，原始完整记录保持无损。记录内 `prompt_context` 不再递归作为未来语境加入。

每次成功翻译原子更新 `data/contexts/<scope_id>/updated.json`：schema、scope_id、records、updated_at、raw_bytes、compressed_bytes、prompt_max_chars、compression、database、table、timezone。该文件不包含原文、译文或密钥；实际记录在数据库。明文历史虽压缩但未加密，压缩不等于保密；备份和共享前自行处理私人内容。

## 0.01.22 · 响应速度 · 2026-11-18

在设置页顶部选择 **响应优先**，再保存设置；停止并重新开始翻译生效。新安装默认采用此组参数，升级时已有自定义值保留。个人 Space Rogue 演示已单独应用该组参数。

| 参数 | 响应优先（新默认） | 均衡占用 |
|---|---:|---:|
| 截图间隔 | 50 ms | 250 ms |
| 文字稳定等待 | 80 ms | 450 ms |
| 翻译并发 | 8 | 4 |
| OCR 区域细化线程 | 4 | 2 |
| 漏识别保留帧数 | 10 | 2 |

保持名义 500 ms 漏识别保留窗口。CPU 忙时帧耗时会改变实际保留时间。可逐项修改；逐字显示的对话建议延长稳定等待，避免中间文本触发额外 API 请求。更高并发会增加瞬时负载，遇到 429 可降低并发。请求次数限制与该预设相互独立。

像素模式的 AUTO 与 SPARSE_TEXT 整帧扫描并行进行，始终按主扫描、补充扫描顺序合并，随后再并行细化真实文字框。各线程使用独立 Tesseract 引擎。256 项识别缓存只复用相同裁切像素、尺寸、语言、原始识别文字和置信度对应的细化文字；位置永远来自当前帧。换字、换语言、置信度变化会失效，失败结果不缓存。此缓存不保存或代替 AI 译文。

流式翻译进行时，UI 最短每 8 ms 消费事件，空闲时为 80 ms；仍按线程队列传递，不从工作线程操作 Tk。连接池保留空闲连接最长 60 秒，仍不跟随重定向且不读取代理环境。后台服务可提前关闭连接；这不是固定网络延迟承诺。

性能测量、首次加载代价及测量边界见 [性能报告](PERFORMANCE_REPORT.md)。原位字体拟合、点击穿透、拖动跟随和过期结果拦截继续保留。
